# Integrations

One folder per integration: `integrations/<developer>/<integration>/`.

- `<developer>` is the developer slug in the Integration Library and equals
  `developer.id` in `manifest.yaml`.
- `<integration>` is the integration slug; `id` in `manifest.yaml` is
  `<developer>.<integration>`. Slugs are unique across the repository.

Start from a [template](../templates/) and follow
[Getting started](../docs/getting-started.md).
